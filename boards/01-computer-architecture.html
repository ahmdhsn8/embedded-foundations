      the shelf

      Material

      Free and open material only. Explanatory reading builds the picture; the manuals are the ground truth.

      Open books

      • Dive into Systems (free, CC BY-NC-ND). Chapter 5 architecture and pipelining, chapter 11 memory hierarchy, chapter 4 binary. Main text.
      • Azeria Labs, Writing ARM Assembly. Free 7-part series on registers, memory access, branches and the stack.
      • Memfault, From Zero to main(). Free. Memory layout and startup.

      ARM, free

      • DUI0553, Cortex-M4 Generic User Guide: programmer's model, memory model, instructions.
      • Cortex-M4 TRM: the 3-stage pipeline and the DWT cycle counter.
      • AAPCS: calling convention.

      ST, free (ground truth)

      • RM0390: memory organization, boot configuration, flash interface.
      • PM0214: core registers, memory model, instruction set.
      • STM32F446 datasheet: clock limits against wait states.

      Tools

      • arm-none-eabi-gcc, objdump, nm, size
      • OpenOCD + arm-none-eabi-gdb (ST-LINK is built into the Nucleo)
      • Pen and paper for the hand traces
      • Optional later: a scope or logic analyzer to cross-check cycle counts with a GPIO toggle
      the lab · sub-chunk 8 project

      Cycle-counting lab

      One short program, one table of measurements, and an explanation for every number. Status: not started.

      1. Turn on the counter. Set TRCENA in DEMCR, reset DWT_CYCCNT, set CYCCNTENA in DWT_CTRL. Read it before and after the code under test.
      2. Measure the empty gap. Two reads back to back. Subtract this overhead from every later number.
      3. Arithmetic. Integer add, multiply, divide. Then float add, multiply, divide with the FPU on, and once with it off.
      4. Memory. Aligned vs unaligned word reads. Loop in flash vs the same loop copied to RAM.
      5. Wait states. Same loop at 0 to 5 wait states, with and without the instruction cache and prefetch.
      6. Control loop. A fixed-point PID step vs a float PID step. Cycles per call, and the jitter over 1000 calls.
